### THE ZSL MATRIX

Use this guide to understand which license applies to your repository. Do not mix them up.

*   **`ZSL-PR`**: The base license. Use it, copy it, modify it. Just keep the copyright notice. No commercial restrictions.
*   **`ZSL-PR-CU`**: Permissive, but you **must** give explicit credit to the original author. No hiding their name.
*   **`ZSL-PR-SH`**: Permissive, but **no commercial use**. You cannot sell it, host it as a paid SaaS, or use it to generate revenue. 
*   **`ZSL-PR-PS`**: Permissive, but if you modify it or host it, your source code **must be public**. No hiding your changes behind a closed API.
*   **`ZSL-PR-CU-SH-PS`**: The Mega-Lock. You must give credit, you cannot monetize it, and your modified source code must remain public.
*   **`ZSL-LT`**: The Time-Bomb. Strict commercial restrictions apply for a set number of years. After the timer hits zero, the code automatically transforms into MIT, Apache 2.0, or BSD.

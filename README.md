# ZANOP SOFTWARE LICENSES

For context (if you are confused), here are the meanings of these acronyms. Read carefully. If you guess wrong, that is a violation of the "Jargon Misunderstanding" clause.

**PR**:
> Stands for permissive use. *NOT PUBLIC RELATIONS*

**LT**:
> Stands for limited time. *NOT LIEUTENANT*

**CU**:
> Stands for credited use. *NOT SEE YOU*

**SH**:
> Stands for non-commercial (share-alike). *NOT SHIELD, AND NOT A SOUND EFFECT*

**PS**:
> Stands for public source code viewing. *NOT PLAYSTATION, AND NOT POSTSCRIPT*

**ZSL**:
> Stands for Zanop Software License. *NOT ZANOP SECURITY LEVEL*

### THE ZSL MATRIX

Use this guide to understand which license applies to your repository. Do not mix them up.

*   **`ZSL-PR`**: The base license. Use it, copy it, modify it. Just keep the copyright notice. No commercial restrictions.
*   **`ZSL-PR-CU`**: Permissive, but you **must** give explicit credit to Zanop Technologies and the original author. No hiding our names.
*   **`ZSL-PR-SH`**: Permissive, but **no commercial use**. You cannot sell it, host it as a paid SaaS, or use it to generate revenue. 
*   **`ZSL-PR-PS`**: Permissive, but if you modify it or host it, your source code **must be public**. No hiding your changes behind a closed API.
*   **`ZSL-PR-CU-SH-PS`**: The Mega-Lock. You must credit us, you cannot monetize it, and your modified source code must remain public.
*   **`ZSL-LT`**: The Time-Bomb. Strict commercial restrictions apply for a set number of years. After the timer hits zero, the code automatically transforms into MIT, Apache 2.0, or BSD.
